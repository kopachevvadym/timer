Політика конфіденційності

Оновлено 23 жовтня 2026 року. Сервіс: timer.kopachev.life — трекер часу AI-агентів.

Коротко

  • Ми зберігаємо лише те, що потрібно для обліку часу: назви проєктів і задач, час роботи, ваш профіль для входу.
  • Ваш код, вміст файлів і повні промпти не зберігаються.
  • Ваші дані бачите тільки ви. Ми їх не продаємо, не передаємо й не показуємо реклами.
  • Видалити акаунт з усіма даними можна будь-коли в «Налаштуваннях» — одразу й назавжди.

Що ми зберігаємо

  • Профіль для входу. GitHub: числовий id, логін, ім'я, аватар. Google: незмінний ідентифікатор акаунта (sub), пошта, ім'я, фото профілю. Також ваш часовий пояс і налаштування.
  • Облік часу. Проєкти (назва, шлях до папки на вашому комп'ютері, репозиторій git), задачі (назва, нотатки, номер у трекері), записи часу (початок, кінець, ідентифікатор сесії агента).
  • Початок промпту (до 140 символів) — лише якщо ви самі ввімкнули це в «Налаштуваннях». Типово вимкнено.
  • Ключі API й токени доступу — лише у вигляді хешів (SHA-256); самі ключі ми не зберігаємо.

Дані Google

Через вхід Google ми отримуємо лише дозволи openid, email і profile і використовуємо їх тільки для того, щоб упізнати вас під час входу та показати ваше ім'я й пошту в «Налаштуваннях». Ми не маємо доступу до вашої пошти, файлів чи інших сервісів Google. Використання даних, отриманих через API Google, відповідає Google API Services User Data Policy, зокрема вимогам Limited Use.

Cookie

Лише необхідні: cookie сесії (щоб ви лишалися в системі) і тимчасова cookie під час входу (захист від підробки запиту). Аналітики й рекламних cookie немає.

Де зберігаються дані

Сервіс працює на інфраструктурі Cloudflare (Workers, D1, KV). Cloudflare обробляє дані як постачальник хостингу. Інших отримувачів немає.

Видалення та ваші права

«Налаштування» → «Небезпечна зона» → «Видалити акаунт» безповоротно видаляє профіль, проєкти, задачі, записи й ключі. Відв'язати GitHub чи Google можна там само. Ви можете будь-коли переглянути й змінити свої дані в інтерфейсі.

Контакт

Питання щодо даних — через github.com/kopachevvadym/timer/issues.

Summary in English

timer stores only what time tracking needs: your sign-in profile (GitHub id/login/name/avatar; Google account id, email, name, picture), project and task names, folder paths, git repository names and time entries. No source code, file contents or full prompts are stored. Google data (openid, email, profile) is used solely to identify you at sign-in, in line with the Google API Services User Data Policy including Limited Use requirements. Data is never sold or shared; hosting is provided by Cloudflare. You can delete your account and all data at any time in Settings.
